
TouchFlow —— 把播放队列以coverflow的形式搬到 Touch Bar 上。

一条可以用手指翻的封面流，左右拖动选歌，点一下直接播放。歌名、歌手、
进度、歌词、第几首，全在触控栏上，不用再把音乐软件调到前台。专为带
Touch Bar 的 MacBook Pro 做的。

它解决什么问题
----------------------------------------------------------------

听歌的时候，想切一首，得先 ⌘Tab 、找到播放器、点下一首、再
切回来——如果只是想在歌单里挑一首，还得打开播放列表，滚半天。

TouchFlow 把这件事搬到了 Touch Bar 上。

打开它，你的播放队列会变成触控栏上的一条封面流：中间一张主封面，两侧
的封面沿透视退远、逐级变小，像一排立起来的唱片。手指左右一拖，它会带
着惯性滑过去，松手回弹到最近的一张；点哪张，就播哪首。

信息栏在左边，一眼能看全：小封面、歌名、歌手、第几首/共几首、播放状态
和当前时间。


它能做什么
----------------------------------------------------------------

· 翻着选歌

  封面流不是装饰，是真的能翻。拖动有惯性和回弹，点一下封面直接播；
  点远处的封面也能点准，不会串到邻座——因为认的是歌曲 ID，不是标题。


· 歌词

  当前歌有 LRC 就显示一句。长句会循环滚动，或者自动缩小字号整句显示
  ——你选。字号、两侧渐隐都能调。

· 外观随你

  封面大小、倾斜角度、封面间距、主封面两侧距离、主封面/侧封面圆角、
  渐隐强度、歌词字号和滚动速度……十几项，改完即时生效，一键恢复默认。

· 不抢你的前台

  这是它和「另一个播放器」最大的区别：打开后播放器仍然在最前面，
  TouchFlow 只占触控栏。关掉，就干净地回到网易云。

· 顺手的小事

  菜单栏常驻，⌃⌥C 随时打开；关掉时不会把你从音乐里弹出去；菜单里可以
  一键「以调试模式启动」，也可以让触控栏保持常亮。


适合谁
----------------------------------------------------------------

· 用网易云音乐桌面版听歌的人

· 机器是 2016–2020 年带 Touch Bar 的 MacBook Pro（Intel 或 M1 都行）

· 喜欢「不离开当前窗口就能操作」的人


前提
----------------------------------------------------------------

· macOS 12 或更高

· 网易云音乐桌面端（官网版/app store版都可以）

· 应用没有签名，第一次打开设置——>隐私与安全性——>最下面“仍要打开”
